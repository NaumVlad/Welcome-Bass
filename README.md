# Шломо & Діна — електронне запрошення

Односторінкове адаптивне запрошення на заручини, створене за наданим візуальним прикладом.

## Локальний перегляд

Відкрийте `index.html` у браузері або запустіть будь-який локальний статичний сервер у корені проєкту.

## Публікація

Сайт підготовлений для GitHub Pages: головна сторінка розташована в корені репозиторію, додаткове складання не потрібне.
